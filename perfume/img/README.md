# Photos

**Notes:** save as `notes/<note-name>.jpg`, lowercase with hyphens:
`bergamot.jpg`, `black-pepper.jpg`, `violet-leaf.jpg`, `tonka-bean.jpg`.
Square, about 300×300. Any note without a photo shows the drawn icon instead.

**Bottles:** save as `bottles/<perfume-id>.png` (transparent background is best), then add
`photo: "img/bottles/<perfume-id>.png"` to that perfume in `perfumes.js`.

Use photos you own, brand press-kit images you're permitted to use, or licensed stock / AI-generated images.
Do not copy images from Fragrantica or other review sites.
